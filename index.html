Retrospective

Reflection

The three months showed the value of a clear sequence: theory first, then deliberate time inside an existing codebase through building and reviewing, then opening changes. Habits such as testing pull requests locally, learning a project’s review language, and paying attention to what maintainers were focused on made later contributions more effective.
